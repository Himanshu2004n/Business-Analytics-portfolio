📊 Healthcare No-show Analysis Dashboard


📌 Project Overview
This project analyzes patient appointment data to identify key factors driving missed appointments (no-shows). Using Python for data preprocessing and Power BI for visualization, it provides insights to improve scheduling efficiency and patient attendance.

📂 Dataset
~70,000 patient appointment records
Features include: age, gender, wait time, SMS reminders, and neighbourhood

🛠️ Tools & Technologies
Python (Pandas) – Data cleaning & preprocessing
Power BI – Interactive dashboard & visualization
CSV/Excel – Data storage


📊 Dashboard Structure
🔹 Page 1: Overview & Key Drivers
Total Visits: ~70K
No-show Rate: ~28.5%
Average Wait Time: ~14.5 days
No-show Rate vs Wait Time
No-show Rate by Age Group


🔹 Page 2: Behavior & Risk Analysis
No-show Rate by SMS Reminder
Top High-risk Neighbourhoods (filtered for statistical significance)
Risk Segmentation (High vs Low based on wait time)
Interactive filters (age group, gender, location)

🧠 Key Insights
~28.5% of appointments result in no-shows
Wait time is the strongest driver, with rates increasing significantly beyond 3 days
Younger patients (<35) show higher no-show rates (~33–34%)
SMS reminders have limited impact
Certain neighbourhoods consistently show higher no-show rates (~35–38%)


💡 Recommendations
Reduce scheduling delay below 3 days
Prioritize high-risk patients for follow-ups
Use targeted reminder strategies
Optimize scheduling for high-risk locations
