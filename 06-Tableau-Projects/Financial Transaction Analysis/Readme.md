# 📊 Financial Transaction Analysis Dashboard (Tableau)

## 📌 Overview

This project presents an interactive Tableau dashboard analyzing financial transaction data to uncover trends, user behavior, and spending patterns.

The dashboard combines business metrics with behavioral analytics to provide a comprehensive view of transaction activity.

---

## 🎯 Objectives

* Analyze transaction volume and value trends
* Understand spending patterns across transaction types
* Study user behavior using login frequency and session duration
* Identify distribution of transaction sizes
* Compare regional performance

---

## 📊 Dashboard Highlights

### 🔹 Key KPIs

* Total Transaction Amount: ₹39.5M
* Total Transactions: 78,600
* Average Transaction Value: ₹502

---

### 🔹 Time-Based Analysis

* Monthly transaction trends show stable performance with minor fluctuations
* Hourly distribution indicates consistent activity throughout the day

---

### 🔹 Category Analysis

* Purchase and Sale transactions dominate total value
* Scam and Phishing transactions are minimal but critical from a risk perspective

---

### 🔹 Distribution Analysis

* Majority of transactions fall within the **medium value range**
* Histogram shows a near-normal distribution with a slight right skew

---

### 🔹 Behavioral Insights

* Login frequency shows **weak correlation** with transaction value
* Session duration reveals an **inverse relationship** with transaction size

  * Short sessions → higher transaction values
  * Longer sessions → lower transaction values

---

### 🔹 Regional Insights

* Transaction values are evenly distributed across regions
* No single region dominates overall contribution

---

## 🧠 Key Insights

* Transaction volume remains stable across months
* Medium-value transactions dominate overall activity
* High-value transactions are limited but significant
* User activity does not strongly influence transaction size
* Session duration plays a key role in transaction behavior
